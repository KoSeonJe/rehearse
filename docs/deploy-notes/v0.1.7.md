## 핵심 변경

### GA4 gtag 수집 복구 (PR #565)

**근본 원인**: prod GA4 (`G-LPQGSG06GF`) 연동에 사용하던 커스텀 gtag 함수가 배열 인자를 스프레드로 push (`(...args) => dataLayer.push(args)`) 하도록 구현되어 있었음. gtag.js 디스패처는 이 형태를 레거시 경로로 라우팅하며, 그 결과 `js` / `config` / `page_view` / 커스텀 이벤트 등 모든 커맨드가 조용히 폐기됨 — 에러 없이 `google-analytics.com/g/collect` 요청 자체가 0건 발생.

**수정 내용**:
- gtag 디스패치를 arguments 객체 기반으로 변경: `function(){ dataLayer.push(arguments) }`
- 초기화 커맨드에 `gtag('js', new Date())` 추가
- 페이지 추적 파라미터를 `page_path` → `page_location` 으로 전환

**변경 파일**: `frontend/src/lib/analytics-client.ts`, `frontend/src/lib/__tests__/analytics-client.test.ts`
