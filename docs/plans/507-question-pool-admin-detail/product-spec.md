# Product Spec — Question Pool Admin Detail Management

## Why

질문 풀 어드민 목록은 질문과 모범답안이 짧게 잘려 보여 운영자가 row의 전체 내용을 확인하기 어렵다. 또한 잘못 등록된 질문을 수정하거나 운영에서 제외할 수 없어 데이터 관리가 불편하다.

## Goal

관리자가 `/admin/question-pool`에서 row 상세를 확인하고, 단일 수정/비활성화 및 선택 row 일괄 비활성화를 수행할 수 있다.

## Scope

- 목록 row 클릭 시 상세 모달을 연다.
- 상세 모달에서 row의 모든 열 값을 표시한다.
- 상세 모달에서 단일 row를 수정한다.
- 상세 모달에서 단일 row를 비활성화한다.
- 목록에서 row를 선택하고 선택 row를 일괄 비활성화한다.
- 삭제는 물리 삭제가 아니라 `isActive=false` 비활성화로 처리한다.

## Acceptance Criteria

- [ ] row 클릭 시 상세 모달이 열린다.
- [ ] 상세 모달에 캐시 키, 세부 주제, 질문, TTS 문구, 모범답안, 상태, 생성일이 표시된다.
- [ ] 상세 모달에서 수정 후 저장하면 목록 데이터가 갱신된다.
- [ ] 상세 모달에서 비활성화하면 해당 row가 `isActive=false`가 된다.
- [ ] 목록에서 선택한 row들을 일괄 비활성화할 수 있다.
