# Comments Rule

## 원칙

- 기본 주석 ZERO. 코드/네이밍이 WHAT 표현.
- 동료 개발자에게 전달할 비명시적 포인트 있을 때만 작성.
- 1-2줄 이내. 다단락 docstring 금지.
- 한국어로 작성.

## 금지

- WHAT 설명 (`// 사용자 ID 가져옴` X).
- 현재 task/PR/이슈 참조 (`// fix for #123` X).
- 제거된 코드 흔적 (`// removed: ...` X).
- 자명한 함수 위 docstring 추가.

## TODO 허용

형식: `// TODO(<담당자>, YYYY-MM-DD): <내용>`

- 당장 안 하지만 추후 해결 필요 사항만.
- 담당자명 + 날짜 필수.
- 한국어로 작성.
- 예: `// TODO(seonje, 2026-05-15): 캐시 TTL 동적 설정으로 변경`
